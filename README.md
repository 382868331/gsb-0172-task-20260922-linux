# OFDM 循环前缀边界与子载波恢复（本题契约子集）

离线数字通信练习库：在含**时偏、频偏、最多 3 抽头固定复数 FIR 信道与
前置噪声**的接收信号中定位 N=32 / CP=8 的合成帧，估计载波频偏并补偿，
用训练符号（前导）做 3 抽头信道最小二乘估计，ZF 均衡后判决恢复 QPSK
符号与位串；信道频响的**深零点载波标记为擦除**，不伪造判决。

**只实现题目定义的有限子集，不是、也不宣称兼容任何完整行业标准（如 802.11/LTE）。**

## 环境与依赖

* Python **3.14.7**（3.10+ 语法即可运行，开发与验收在 3.14.7）。
* **仅标准库**（`math`、`cmath`、`dataclasses`、`unittest`）。安装 Python 后
  无需安装任何其他依赖；核心、测试、演示全部离线，无网络/账号/硬件/数据库。
* 核心算法（相关、频偏估计、DFT/IDFT、3×3 复最小二乘、QPSK 判决）全部在
  `ofdm_recovery/core.py` 内手写，没有用第三方同类实现代替。

## 帧结构（固定常量）

| 项 | 值 |
|---|---|
| FFT 点数 N / 循环前缀 CP | 32 / 8 |
| 前导（训练符号） | 两个相同的 16 样本复块（32 样本），块内容见 `TRAINING_BLOCK` |
| OFDM 符号 | 2 个，每个 40 样本（CP + 32） |
| 帧长 | 112 样本 |
| 数据载波 | ±1..±6（DFT 索引 1..6、26..31），QPSK，共 24 符号/帧 |
| 导频载波 | +7（索引 7，已知 +1）、−7（索引 25，已知 −1） |
| DC 与其余载波 | 0 |
| 信道 | 固定复数 FIR，**最多 3 抽头**：`y[n]=h0·x[n]+h1·x[n-1]+h2·x[n-2]`，帧起点前为静默 |
| 输入信号长度上限 | **512 样本**（含帧前后噪声） |

QPSK 星座为 `±(1+j)/√2`。位映射：每位对应一个坐标，实部在前、虚部在后，
正→`0`、负→`1`。符号输出顺序：符号 0→1，每符号载波 −6..−1、+1..+6；
共 24 符号、48 位。

## 公开接口

```python
from ofdm_recovery import decode, find_candidates, dft, symbols_to_bits, DecodeResult
```

### `decode(signal, *, rho_threshold=0.85, residual_threshold=0.35, erasure_threshold=0.1, max_candidates=1024) -> DecodeResult`

离线恢复一帧。`signal` 为 `list/tuple`，元素为 `int/float/complex`（长度 1..512）。
新增关键字参数 `erasure_threshold`（正有限数）：数据载波 k 满足
`|H(k)| < erasure_threshold · rms(H)` 时判为深零点并擦除；
`rms(H) = sqrt(|h0|²+|h1|²+|h2|²)`（由 Parseval，即全载波频响模值的 RMS）。
返回不可变 `DecodeResult`：

| 字段 | 含义 |
|---|---|
| `start` | 帧起点（前导第一样本）下标 |
| `frequency_offset` | 频偏估计，单位载波间隔，满足 `|f| < 0.5`（稳态窗估计，多径下无偏） |
| `residual` | 选中候选的前导相关残差 `1 − 2|C|/(E1+E2)`，∈[0,1]；**多径下因瞬态项非零**，帧质量请看 `channel.fit_residual` |
| `gain` | 四个导频观测最小二乘的单一复增益（历史字段；多径下等于 `(H(7)+H(25))/2`，仅作参考，均衡不依赖它） |
| `symbols` | 24 个判决符号（顺序见上）；**被擦除位置为 `None`** |
| `bits` | 48 字符位串；**被擦除符号对应的两位为 `'x'`** |
| `channel` | `ChannelEstimate`：3 抽头估计与频域结果（见下） |
| `erased_carriers` | 被判深零点的有符号数据载波元组（如 `(3,)`），无擦除为 `()` |
| `erased_positions` | 24 个数据符号中被擦除的位置索引元组 |

`ChannelEstimate` 字段：`taps`（恒 3 个复抽头）、`rms_gain`、
`frequency_response`（32 点 `H[k]`）、`erased_carriers`、
`fit_residual`（训练拟合归一化残差 J，无噪声任意多径下 ≈0）。

### `find_candidates(signal, *, rho_threshold=0.85, max_candidates=1024) -> list[Candidate]`

穷举**全部**可行起点（前导 32 样本能完整放入的位置），计算延迟 16 的自相关
`C(p)=Σ x[p+m+16]·conj(x[p+m])` 及两块能量 E1/E2。
保留 `coherence = |C|²/(E1·E2) ≥ rho_threshold` 的全部候选
（零能量静默位置跳过），按 **(残差升序, 起点升序)** 排序。
`Candidate` 字段：`start / frequency_offset / residual / coherence`。
多径下的起点终审在 `decode` 内完成（见算法一节），本函数只做相关枚举。

其余接口：`dft(x)`（任意长度朴素 DFT，无归一化）、
`symbols_to_bits(symbols)`（符号可为 `complex` 或 `None`，`None`→`'xx'`）。

### 错误语义（均可定位、不静默纠正）

所有错误继承 `OFDMError(ValueError)`：

| 异常 | 触发条件 |
|---|---|
| `SignalFormatError` | 信号类型错、空、长度 >512、某样本为 NaN/Infinity（消息带 `signal[i]`）、bool 样本 |
| `ParameterError` | 阈值不在合法区间、NaN/Infinity、`max_candidates` 非正整数、bool 当数值 |
| `NoFrameError` | **穷举全部可行起点后证明无候选**（消息含扫描数量），区别于预算耗尽 |
| `SearchBudgetError` | 候选数超过 `max_candidates`，消息明确声明“这是预算限制，不证明帧不存在” |
| `FrequencyOffsetError` | 选中起点频偏 `|f| ≥ 0.5`，超出契约区间 |
| `FrameQualityError` | 所有候选的前导残差都 > `residual_threshold`（含“相关很高但幅度失配”） |
| `TruncatedFrameError` | 前导定位成功，但信号在 112 样本帧结束前截断 |
| `ZeroPilotEnergyError` | 信道模型预测导频有能量但观测为零（发射端未发导频）；导频处恰为信道零点属合法深零，不拒绝 |
| `ChannelEstimateError` | 训练符号上 3 抽头 LS 正规方程奇异，无法估计信道 |

整数参数拒绝 `bool`；所有标量数值拒绝 NaN/Infinity；
`erasure_threshold` 必须为**正有限数**（允许任意小，调用方自担数值风险）。
操作无共享可变状态（纯函数），失败即抛异常，不产生部分结果，
输入信号不被修改（有测试断言）。

## 算法与设计取舍

1. **定时同步**：延迟 M=16 的全窗口自相关枚举所有候选（与上一版一致）。
2. **定时等价类与规范形式**：≤3 抽头下，"起点 p、抽头 (h0,h1,0)" 与
   "起点 p−1、抽头 (0,h0,h1)" 产生**完全相同的波形**（延迟被抽头吸收），
   单抽头时等价类宽达 ±2。`decode` 对每个候选做训练符号 3 抽头联合 LS
   （第一块因果零前史 + 第二块循环卷积，共 32 方程），得归一化拟合残差 J；
   在 J 等价带（`J ≤ max(1.1·J_min, 1e-6)`）内按
   **(|h0|/rms 降序, 前导残差, 起点)** 取规范形式——即等价类中
   "首抽头非零"的最晚起点，无噪声下与真实起点一致（有测试逐点验证）。
3. **频偏估计**：稳态窗口（第二块 m=2..15）相关相位 `f = arg(C)/π`，
   避开 FIR 拖尾占据的每块前 2 样本，多径下无偏；补偿乘子
   `exp(−j2πf n/32)`，时间原点取帧起点（绝对相位被抽头吸收）。
4. **信道估计**：训练符号 32 样本 × 3 抽头的复最小二乘，
   正规方程 3×3 高斯消元（部分选主元，手写）。无噪声下抽头恢复到
   机器精度（实测 ~1e-16）。
5. **均衡与擦除**：`H(k)=Σ_l h_l exp(−j2πkl/32)`，数据载波 ZF 均衡
   `X̂=Y/H` 后硬判决；`|H(k)| < erasure_threshold·rms(H)` 的载波判擦除
   （符号 `None`、位 `'x'`），不做硬判决。默认门限 0.1：精确零点的
   邻载波相对响应为 `2sin(π/32)/√2 ≈ 0.139`，不会被误擦。
6. **导频的角色**：导频不再用于均衡（训练符号已足够），仅保留两个用途：
   历史字段 `gain`（导频 LS 标量增益）与"发射端未发导频"的拒绝检查
   （模型预测导频有能量但观测为零 → `ZeroPilotEnergyError`）。
7. CP=8 足以吸收 3 抽头拖尾与定时小幅滑动；去 CP 后每符号做手写 DFT。

## 浮点误差口径（明确，不用宽容差掩盖边界错误）

以下为确定性测试中实测/断言的口径，测试用固定种子噪声、真实计算：

* **无噪声、任意 ≤3 抽头信道**：起点**精确**；频偏绝对误差 `< 1e-9`；
  抽头绝对误差 `< 1e-9`（实测 ~1e-16）；训练拟合残差 `J ≈ 0`（~1e-32）；
  未擦除位 48/48 全对；擦除载波集合与解析式 `|H(k)| < 0.1·rms(H)`
  逐点一致（±1..±6 每个载波的精确零点都枚举测过）。
* **平坦信道（单抽头）**：与上一版口径完全一致——起点精确；频偏、增益
  绝对误差 `< 1e-9`；48 位全对；相关残差 `=0` 到 `1e-12`。
* **前置+带内噪声**（三角分布复噪声，幅度参数 0.05）：起点精确；
  频偏绝对误差 `< 0.02`；抽头绝对误差 `< 0.05`（实测 ~0.01）；
  48 位全对。噪声更大时位错误属物理现象，库不承诺 SNR 性能曲线。
* **深零点擦除**：零点载波估计频响 `< 1e-9`（相对 RMS `< 1e-15`）；
  噪声 0.02 下擦除判定与未擦除位仍正确。
* **边界**：`|cfo|=0.49` 可恢复；`|f|≥0.5` 必然被 `FrequencyOffsetError` 拒绝。
  信号长度 = 512（时偏 400+帧 112）可正常解码，长度 = 513 抛 `SignalFormatError`。
* DFT 单元测试对已知变换对（冲激、直流、单频）误差 `< 1e-10`。

## 已知限制

* 仅支持本文件固定的 N=32/CP=8/2 符号/QPSK/±7 导频布局，不可配置成其他制式。
* 信道为**帧内固定**的最多 3 抽头复数 FIR + 载波频偏；不处理更长的多径、
  采样钟偏差、相位噪声、帧间信道变化；无纠错编码、无交织。
* 定时等价类是物理固有歧义：真实信道若首抽头恰为 0（纯延迟信道），
  报告起点为规范形式（等价类最晚起点），与发射端标称边界可差 1–2 样本——
  波形层面不可区分，且恢复位串相同。
* 频偏估计范围严格限于 `|f|<0.5` 载波间隔（契约要求），不做整数倍频偏搜索。
* 深零点载波直接擦除，不做插值/外推恢复；擦除门限需调用方按场景调整时
  用 `erasure_threshold`。
* 朴素 O(N²) DFT（N 固定 32），未做 FFT 优化——本题规模无此必要。
* 不做 AGC、不输出软信息；DC 与空载波不参与判决。

## demo 说明

`python demo.py` 用确定性独立合成器实时计算并打印：

1. **正常帧**：3 抽头 FIR + 时偏 23 + 频偏 +0.137 + 固定种子噪声 0.05，
   恢复起点、频偏、三个抽头（与真实值并排打印）与 48 位位串；
2. **深零点擦除边界**：信道 `[1, −exp(j2π·3/32)]` 在数据载波 +3 上有
   解析精确零点，该载波两位标 `'x'`，其余 44 位全部恢复；
3. **坏帧**：多径下前导可定位但帧内截断，实际抛出 `TruncatedFrameError`；
4. **非法参数**：`erasure_threshold=0.0` 实际抛出 `ParameterError`。

无 sleep、无预录结果，全程实测 < 0.1 s。

# OFDM 循环前缀边界、子载波恢复与 FIR 信道均衡（本题契约子集）

离线数字通信练习库：在含**时偏、频偏、固定复数 FIR 信道（最多 3 抽头）与
前置/带内噪声**的接收信号中定位 N=32 / CP=8 的合成帧，估计载波频偏并补偿，
去循环前缀后自行做 DFT，用**已知训练前导联合 ±7 导频**最小二乘估计 FIR
抽头，逐数据载波频域均衡后判决 QPSK 符号与位串；信道频率响应的**深零点
载波标记为擦除**（不强行判决）。

**只实现题目定义的有限子集，不是、也不宣称兼容任何完整行业标准（如 802.11/LTE）。**

## 环境与依赖

* Python **3.14.7**（3.10+ 语法即可运行，开发与验收在 3.14.7）。
* **仅标准库**（`math`、`cmath`、`dataclasses`、`unittest`）。安装 Python 后
  无需安装任何其他依赖；核心、测试、演示全部离线，无网络/账号/硬件/数据库。
* 核心算法（相关、频偏估计、DFT/IDFT、训练+导频 LS 信道估计、ZF 均衡、
  QPSK 判决）全部在 `ofdm_recovery/core.py` 内手写，没有用第三方同类实现。

## 帧结构（固定常量）

| 项 | 值 |
|---|---|
| FFT 点数 N / 循环前缀 CP | 32 / 8 |
| 前导（训练符号） | 两个相同的 16 样本复块（32 样本，chirp-like，接收机已知） |
| OFDM 符号 | 2 个，每个 40 样本（CP + 32） |
| 帧长 | 112 样本 |
| 数据载波 | ±1..±6（DFT 索引 1..6、26..31），QPSK，共 24 符号/帧 |
| 导频载波 | +7（索引 7，已知 +1）、−7（索引 25，已知 −1） |
| DC 与其余载波 | 0 |
| 信道模型 | 最多 **3** 抽头固定复数因果 FIR `y[n]=Σ_{l=0}^{L-1} h_l x[n-l]` + 载波频偏 |
| 输入信号长度上限 | **512 样本**（含帧前后噪声） |

QPSK 星座为 `±(1+j)/√2`。位映射：每位对应一个坐标，实部在前、虚部在后，
正→`0`、负→`1`。符号输出顺序：符号 0→1，每符号载波 −6..−1、+1..+6；
共 24 符号、48 位。

## 公开接口

```python
from ofdm_recovery import (
    decode, find_candidates, dft, symbols_to_bits, DecodeResult,
    MAX_CHANNEL_TAPS, DEFAULT_CHANNEL_TAPS, DEFAULT_ERASURE_THRESHOLD,
    ChannelEstimateError,
)
```

### `decode(signal, *, rho_threshold=0.85, residual_threshold=0.35, max_candidates=1024, channel_taps=3, erasure_threshold=0.25) -> DecodeResult`

离线恢复一帧。`signal` 为 `list/tuple`，元素为 `int/float/complex`（长度 1..512）。
新增两个关键字参数（默认值保持旧调用完全可用）：

| 参数 | 含义 |
|---|---|
| `channel_taps` | FIR 抽头数 L，整数且 `1 ≤ L ≤ 3`（默认 3）。L=1 即旧的单一平坦复增益模型，定时/频偏/增益的全部旧口径保持不变。 |
| `erasure_threshold` | 深零点擦除门限，闭区间 `[0,1]` 内有限实数（默认 0.25）。数据载波满足 `|H(k)|/sqrt(Σ_l|h_l|²) < erasure_threshold` 时标记擦除。0.0 = 从不擦除；1.0 = 所有数据载波都擦除。 |

返回不可变 `DecodeResult`：

| 字段 | 含义 |
|---|---|
| `start` | 帧起点（前导第一样本）下标 |
| `frequency_offset` | 频偏估计（L>1 时在瞬态安全窗上精化），载波间隔为单位，`|f| < 0.5` |
| `residual` | 前导瞬态安全窗（剔除前 L−1 个受 FIR 拖尾污染的样本对）归一化失配能量，∈[0,1]；L=1 时即旧的全窗残差 |
| `gain` | `channel[0]`（第 0 抽头）；L=1 时就是旧契约的单一复增益 |
| `channel` | 估计抽头元组 `(h_0, …, h_{L-1})`（含整体复增益，L 由参数指定） |
| `symbols` | 24 个判决符号；非擦除载波为 `±(1±j)/√2`，**深零点擦除载波为 `None`** |
| `bits` | 48 位位串；擦除符号的两位标记为 `'x'`，其余为 `'0'/'1'` |
| `erased` | 被擦除数据载波的有符号下标元组（取自 ±1..±6），两符号共用同一组擦除载波 |

### `find_candidates(signal, *, rho_threshold=0.85, max_candidates=1024) -> list[Candidate]`

**本迭代未改签名与语义**，L=1 的 `decode` 仍直接使用它。穷举全部可行起点
（前导 32 样本能完整放入的位置），在**完整 16 点窗**上计算延迟 16 的自相关
`C(p)=Σ x[p+m+16]·conj(x[p+m])` 及两块能量 E1/E2，保留
`coherence = |C|²/(E1·E2) ≥ rho_threshold` 的全部候选（零能量静默位置跳过），
按 **(全窗残差升序, 起点升序)** 排序。注意：全窗统计对 L>1 的 FIR 信道会把
前 L−1 个瞬态样本对计入，弱首径信道在真起点的全窗相干系数可能跌破 0.85
（实测最低约 0.84），因此 L>1 的 `decode` **不使用**这个全窗门限，而是在
瞬态安全窗上重新门控（见算法第 2 点）；`find_candidates` 的旧行为本身保持不变。

其余接口：`dft(x)`（任意长度朴素 DFT，无归一化）、`symbols_to_bits(symbols)`
（旧辅助函数，输入须全部为 complex；擦除位请直接使用 `DecodeResult.bits`）。

### 错误语义（均可定位、不静默纠正、无半更新状态）

所有错误继承 `OFDMError(ValueError)`：

| 异常 | 触发条件 |
|---|---|
| `SignalFormatError` | 信号类型错、空、长度 >512、某样本为 NaN/Infinity（消息带 `signal[i]`）、bool 样本 |
| `ParameterError` | 阈值不在规定区间、NaN；`max_candidates` 非正整数；`channel_taps` 不是 1..3 的非 bool 整数；`erasure_threshold` 不在 [0,1]；bool 当整数 |
| `NoFrameError` | **穷举全部可行起点后证明无候选**（消息含扫描数量），区别于预算耗尽；全零 FIR 帧也落在这里 |
| `SearchBudgetError` | 候选数超过 `max_candidates`，消息明确声明“这是预算限制，不证明帧不存在” |
| `FrequencyOffsetError` | 最优候选频偏 `|f| ≥ 0.5`，超出契约区间 |
| `FrameQualityError` | 最优候选残差 > `residual_threshold` |
| `TruncatedFrameError` | 前导定位成功，但信号在 112 样本帧结束前截断 |
| `ZeroPilotEnergyError` | ±7 导频能量低于总能量的 `1e-9` 相对底限，无法估计信道 |
| `ChannelEstimateError` | 训练/导频法方程奇异或解出全零抽头（正常帧不会触发；保留为可定位的估计失败） |

整数参数拒绝 `bool`；所有标量数值拒绝 NaN/Infinity。纯函数、无共享可变状态，
失败即抛异常，不产生部分结果。

## 算法与设计取舍

1. **定时同步（L=1）**：延迟 M=16 的全窗自相关找重复前导块；相干性门限
   枚举**所有**候选，按 (残差, 起点) 排序——纯幅度缩放的两块
   `coherence=1` 但残差很大，会被正确降级。
2. **定时同步（L>1，FIR 模式）**：全窗前 L−1 个样本对受因果拖尾瞬态
   污染，会低估弱首径信道在真起点的相干系数（实测可低至约 0.84）。故
   `decode` 在**瞬态安全窗** m∈[L−1,15]（L=3 时仍有 14 对）上重新门控
   扫描全部可行起点（同样的 `rho_threshold`，纯噪声实测零虚警）；通过后
   对每个候选补偿其安全窗频偏，再对 32 点前导做**全因果训练模型 LS 拟合**
   （块 1 的 n<L 瞬态样本按“前置样本为零”建模，是绝对定时标记；块 2 按
   16 点循环卷积建模），以归一化失配能量排序。物理上“起点提前 δ≤L−1”与
   “抽头整体后移 δ、前补零”严格规范等价（无噪声失配同为 0），因此把
   失配 ≤3 倍最小值（干净时取 1e-12 数值底限）、位置相邻（间隔 ≤L−1）的
   候选归为同一规范簇：多簇并存取最早簇（保留旧的最早帧语义），**簇内取
   最晚起点**（对应 h₀ 非零的物理位置）。实测噪声下规范簇内失配比 ≤1.26，
   而真正晚于真起点的位置无法解释首批瞬态样本、失配比 >1000，分离充分。
3. **频偏估计**：两块相隔 16 样本，相位差 `2πf·16/32 = πf`，故 `f=arg(C)/π`，
   无歧义区间恰为 `|f|<0.5`；补偿乘子 `exp(−j2πfn/32)`。
4. **去 CP + DFT**：每符号跳过前 8 点，对 32 点做手写 DFT。
5. **信道估计**：已知训练前导（时域，32 个方程）联合两符号 × 两导频
   （频域，4 个方程，`Y[k]=p[k]·Σ_l h_l exp(−j2πkc·l/32)`）共 36 个观测，
   组成线性模型后按 `AᴴA·h=Aᴴy` 法方程 + 部分主元高斯消元求 L≤3 个复抽头。
   训练序列提供定时/多径主要信息，导频锚定 OFDM 符号并稳定求解。L=1 时
   训练+导频联合估计的结果与旧的四导频最小二乘增益一致（噪声口径不退化，
   实测误差甚至更小），`channel=(gain,)`。
6. **均衡与擦除**：逐数据载波零 forcing 均衡 `Q(k)=Y(k)/H(k)` 后 QPSK 硬判决；
   `|H(k)|/sqrt(Σ|h_l|²) < erasure_threshold`（默认 0.25）的深零点载波不判决，
   `symbols` 置 `None`、`bits` 置 `'x'`、载波号进 `erased`。擦除集合对两个
   OFDM 符号相同（固定 FIR 的频响在单帧内不变）。
7. CP=8 足够吸收定时小幅滑动；不做插值/MMSE 均衡、不做跨块重搜与跟踪。

## 浮点误差口径（明确，不用宽容差掩盖边界错误）

以下为确定性测试中实测/断言的口径，测试用固定种子噪声、真实计算：

* **L=1 旧口径全部保留**：无噪声起点精确；频偏、复增益绝对误差 `< 1e-9`
  （实测机器精度 `~1e-15`）；48 位全对；残差 ≈0。噪声幅度 0.05（每坐标
  标准差 ≈0.041）下起点精确、频偏误差 `<0.02`、增益模误差 `<10%`、48 位全对。
* **FIR 无噪声**（1/2/3 抽头，含中间抽头为 0）：起点精确、频偏误差 `<1e-9`、
  残差 `<1e-9`、各抽头绝对误差 `<1e-9`（实测 `~1e-16`）；非擦除 48−2·|erased|
  位全部精确恢复；擦除集合与解析公式 `|1−e^{−j2πk/32}|` 等手算结果一致。
* **FIR + 噪声 0.05**（多固定种子）：起点精确；频偏误差 `<0.02`；每抽头
  相对幅度误差 `<10%`；擦除集合在种子间稳定；非擦除位全部正确。深零点
  载波不承诺位正确——它们按契约被擦除。
* **擦除门限边界**：0.0 时不擦除（干净深零点仍可 ZF 恢复，仅噪声余量极小）；
  1.0 时 12 个数据载波全部擦除（24 个符号全 `None`、位串全 `'x'`）。
* **边界**：FIR + `|cfo|=0.45` 可恢复；信号长度 = 512（时偏 400+帧 112）
  可正常解码，513 抛 `SignalFormatError`；`channel_taps` ∈ {0,4,2.0,bool}、
  `erasure_threshold` ∉ [0,1] 一律 `ParameterError`。
* DFT 单元测试对已知变换对（冲激、直流、单频）误差 `<1e-10`。

## 已知限制

* 仅支持本文件固定的 N=32/CP=8/2 符号/QPSK/±7 导频布局，不可配置成其他制式。
* 信道为最多 3 抽头**固定**（单帧内时不变）复数因果 FIR + 载波频偏；帧边界
  已知、无时钟漂移；不做连续流接收、跨块重搜、联合时钟/频偏估计、信道跟踪。
* 深零点载波只做**擦除标记**（`None`/`'x'`），不做纠错编码、交织或删失位填充；
  擦除门限是归一化幅度门限，不是后验可靠性（无软信息输出）。
* 均衡为单载波零 forcing；深零点附近噪声增强由擦除门限规避，不做 MMSE。
* 频偏估计范围严格限于 `|f|<0.5` 载波间隔，不做整数倍频偏搜索。
* 起点提前 δ≤L−1 与抽头后移在无前置样本信息时数学上不可区分；本实现以
  “簇内最晚起点（h₀ 非零）”作为规范，依赖物理信道第 0 径非零。
* 朴素 O(N²) DFT（N 固定 32）与 ≤3 阶小线性方程组，未做 FFT/库优化——
  本题规模无此必要。不做 AGC；DC 与空载波不参与判决。

## demo 说明

`python demo.py`（实测 < 0.1 s）用确定性独立合成器生成一个 2 抽头 FIR 帧
（h=(1,−1)，真实时偏 23、频偏 +0.137、复增益 `1.7·exp(j0.6)`、固定种子
噪声 0.05）：实时打印恢复起点、频偏、残差、3 个估计抽头、解析手算的各载波
归一化幅度与深零点擦除集合 `(-1, 1)`、带 `x` 标记的 48 位位串；随后演示
擦除门限两个极端（1.0 全擦除 / 0.0 干净信号不擦除且全对）；最后实际抛出
两个拒绝：FIR 截断帧 `TruncatedFrameError` 与非法 `channel_taps=4` 的
`ParameterError`。无 sleep、无预录结果。
